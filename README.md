# єДокумент — макет (PWA)

Демонстраційний макет картки документа. Проєкт налаштований як PWA (Progressive Web App), тому його можна "встановити" на телефон як застосунок прямо з браузера — без App Store / Google Play.

## Структура проєкту

```
diia-app/
├── index.html       — сама сторінка (макет картки)
├── manifest.json     — маніфест PWA (назва, іконки, кольори)
├── sw.js             — service worker (офлайн-кеш, потрібен для встановлення)
├── icons/
│   ├── icon-192.png
│   └── icon-512.png
└── vercel.json       — конфіг для Vercel
```

## Деплой на Vercel

### Варіант 1: через сайт vercel.com (найпростіше)
1. Зареєструйтесь / увійдіть на https://vercel.com
2. Створіть новий проєкт → "Add New… → Project"
3. Якщо коду ще немає в GitHub — виберіть спосіб "Deploy without Git" (перетягніть папку `diia-app` цілком) або спершу залийте папку в новий GitHub-репозиторій і підключіть його.
4. Vercel сам визначить, що це статичний сайт (Framework Preset: "Other"), додаткові налаштування білда не потрібні.
5. Натисніть Deploy — за кілька секунд отримаєте посилання виду `https://your-project.vercel.app`.

### Варіант 2: через Vercel CLI (з термінала на своєму комп'ютері)
```bash
npm install -g vercel
cd diia-app
vercel login
vercel --prod
```
CLI запитає назву проєкту і за замовчуванням задеплоїть поточну папку як є.

## Встановлення на телефон як застосунок

Після деплою відкрийте посилання на телефоні:

**Android (Chrome):**
1. Відкрийте посилання у Chrome.
2. Натисніть меню (три крапки) → "Додати на головний екран" / "Установити застосунок".
3. Іконка з'явиться на робочому столі й відкриватиметься на весь екран, без адресного рядка.

**iPhone (Safari):**
1. Відкрийте посилання у Safari (важливо саме Safari, не Chrome — на iOS "Додати на екран Домівки" працює тільки там).
2. Натисніть кнопку "Поділитися" (квадрат зі стрілкою вгору).
3. Виберіть "На екран Домівки".
4. Іконка з'явиться на робочому столі як окремий застосунок.

## Примітки
- Всі дані на картці (ПІБ, дата народження, РНОКПП, фото) — вигадані/демонстраційні, редагуються прямо в застосунку подвійним кліком.
- Це макет для демонстрації дизайну, а не справжній державний сервіс і не має жодного зв'язку з офіційним застосунком "Дія".
